# BioSync Wellness Hub

I am building BioSync, an AI-powered nutritional decision engine combining Western nutrition and TCM energetics. I already generated the initial frontend layout in v0.dev using React, Tailwind CSS, and Shadcn UI.

Please use this exact v0 code present in the attached txt file as the baseline configuration and foundational layout for the app. Render it perfectly. Once loaded, immediately perform the following 1st layout modification: 1. Move the user's "Real-Time Biometric / Somatic State" summary to the top 15% of the viewport. 2. Re-architect the primary meal recommendation into a massive, centralized "Hero Card" taking up roughly 50% of the focal space. 3. Move the complex text-heavy Explainable AI (XAI) rationale breakdowns out of the persistent grid and into a clean, collapsible bottom sheet or drawer overlay.
